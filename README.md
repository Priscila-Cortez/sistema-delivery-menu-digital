# sistema-delivery-menu-digital
Proyecto académico desarrollado en SENATI utilizando PHP y MySQL.
## Descripción
Aplicación web que permite a los clientes visualizar una tabla de productos, realizar pedidos y generar comprobantes PDF.
También incluye un panel administrativo para gestionar productos mediante operaciones CRUD.

## Funcionalidades
- Inicio de sesión para administradores.
- Gestión de productos.
- Registro de pedidos.
- Generación de comprobantes PDF.
- Operaciones CRUD.
- Menú digital.

## Tecnologías utilizadas
- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP
